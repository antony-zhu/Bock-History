### 记录口径

- **当前功能基准**：用户可见功能以顶部列出的实现提交为准；文档提交不改变该基准。
- **历史分支**：提交在本仓库 Git 引用中存在，但不是顶部功能基准的祖先；它保留
  开发成果和待整合事项，不表示已经合入、已发布或已上机。
- **真机结果**：只以受保护的 `device-deploy-456b61a/deployment-report.md` 为准；
  其余没有报告支撑的内容一律标为本地或待确认。

## 维护规则

每次 Block V2 变更只在本文件**追加一条**，并同步更新顶部的功能基准、真机
版本、本地演示状态、已完成/未发布和下一步。每条只保留目标/决策、结果、提交、
验证或真机结论与遗留事项；不要写成逐命令的故障流水账。没有证据的结果必须写
“待确认”，不得补写推测。
