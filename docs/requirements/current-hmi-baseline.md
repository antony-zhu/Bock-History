# 当前网页 HMI 功能基线

## 用途

本文记录现有网页 Demo 已表达的功能，作为 Block 本地 HMI 的产品基线。Block 是可独立运行的单设备产品，当前阶段一台 Block 对应一台设备；本地 HMI 不依赖路由器、BDM、Android Pad 或未来服务器。本文只描述当前行为，不代表所有功能都可以直接用于真实设备控制。该纯静态 Demo 不承载真实业务通信；生产 HMI 必须使用受信 HTTPS，明文 HTTP 版本不得部署。

## 参考来源

- 原始设计：`docs/references/HMI界面说明-料仓.pptx`，共 9 页。
- 可交互版本：`apps/web-hmi/index.html`。
- 设备图片：`apps/web-hmi/assets/machine-bin.png`。

## 页面基线

### 1. 主页

- 顶部展示产线名称、当前日期时间和当前页面名称。
- 展示系统运行状态、抓取 A/B 位、三个库位及其状态。
- 库位示例状态：满料、需换料、异常。
- 展示单件节拍、当日产能、合格率和最近消息。
- 提供清空料仓、启动、暂停、复位、单件循环暂停、单框循环暂停、抽检和模式切换等演示操作。

### 2. 生产数据

- 当日目标产能、单件节拍、当前产能、设备稼动率。
- 抽检数量、合格数量、NG 数量、待检数量。
- 料仓毛坯数量、料仓成品数量和目标完成度。

原 PPT 还提出了产能堆积、订单进度、订单所需资源等能力，并注明部分能力需要配合 MES；这些内容尚未进入网页 Demo。

### 3. 维护设置

- 产能设定。
- 换刀件数设定。
- 抽检间隔设定。
- 当前仅修改页面内模拟状态。

### 4. 报警

- 按提示、警示、报警等级展示代码、内容和时间。
- 支持在页面内模拟确认报警。

### 5. 历史记录

- 展示事件代码、内容和时间。
- 页面内的部分模拟操作会追加历史记录。

## 当前交互与显示约束

- 设备详情以 16:9 横屏为主要布局；窄屏会提示横屏查看。
- 底部导航包含主页、生产数据、维护、报警和历史记录。
- 当前数据不持久化，刷新页面后恢复为初始模拟数据。
- 当前没有工厂、流水线和设备层级，也没有登录、权限、网络异常或数据断连处理。

## 参考稿之间尚未统一的内容

- 主页摘要指标在不同 PPT 页面中出现过“合格率”和“计数换刀”两种版本；当前网页采用“合格率”。
- PPT 中“计数换刀”的示例单位写为 `%`，疑似占位或标注错误，正式实现前应确认真实字段和单位。
- 同类状态存在“加工/运行中”“预备换料/需换料”“紧急补料/异常”等不同用词，需要统一术语。
- 底部导航称为“维护”，对应 PPT 页面标题又称“用户设置”；当前网页使用“维护设置”。
- PPT 只定义报警展示，网页额外加入了“确认报警”交互；是否属于正式需求尚未确认。

## Block 本地 HMI 与 Android Pad 的复用原则

- Block 本地设备详情页在信息内容上以此基线为起点，并在没有 BDM 时保持正常运行。
- Block 本地允许的现场操作需要结合真实 PLC 点位、权限和安全联锁单独确认。
- Android Pad 只在部署 BDM 时使用，可以复用主页、生产数据、报警和历史等只读展示内容，但第一阶段不继承维护参数、控制按钮和告警确认。
- Android Pad 不直接连接 Block 或 PLC；流水线和多设备入口的数据来自 BDM。
- 流水线和设备两级入口属于 BDM/Pad 视角，不改变 Block 本地 HMI“一台 Block 对应一台设备”的边界。
