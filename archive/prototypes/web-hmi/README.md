# 网页 HMI Demo

这是依据 `docs/references/HMI界面说明-料仓.pptx` 制作的现有料仓设备 HMI Demo。

## 文件

- `index.html`：页面结构、样式、模拟状态和交互逻辑，目前集中在单个文件中。
- `assets/machine-bin.png`：主页使用的料仓设备示意图。

## 当前功能

- 主页：设备运行状态、抓取位置、库位状态、生产指标和当前消息。
- 设备操作演示：清空料仓、启动、暂停、复位、循环暂停、抽检、自动/手动切换。
- 生产数据：目标产能、节拍、产能、稼动率、抽检和料仓数量。
- 维护：产能、换刀件数和抽检间隔的模拟设置。
- 报警：报警列表和模拟确认。
- 历史记录：展示并追加本次页面操作记录。

## 当前限制

- 所有数据和操作都只存在于浏览器内，不连接服务器或 PLC。
- 本项目是纯静态模拟，不承载真实业务通信；任何接入真实数据的版本必须使用 HTTPS/MQTTS/WSS，并拒绝明文访问。
- 画面以 1600 × 900 的 16:9 横屏 HMI 为设计基准，再按窗口等比缩放。
- 当前版本是设备详情页基线，不包含“流水线列表”和“设备列表”两级入口。
- 该 Demo 不是生产控制软件，按钮只用于界面演示。
